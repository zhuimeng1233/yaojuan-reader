## ✨ 核心特色

### 1. 独家「双层章节树」与极速排版引擎
- **原生双层结构解析**：完美识别一级章节（`# 第X章`、`第X章`、`Chapter X`）与二级分幕（`## 分幕 X-Y · 标题`），无缝兼容剧本式小说、长篇生成系统与传统网文。
- **百章卷分组（Lazy TOC）**：超千章长篇自动按百章分卷，仅渲染当前展开卷的章节，减少首屏目录 DOM 数量。
- **全量字符自适应解码**：智能探测 UTF-8 / GB18030 / GBK / UTF-16 编码，采用全量缓冲校验机制，杜绝截断中文导致误退回乱码的问题。
- **章节级虚拟视口**：阅读器只保留当前活动章节的正文 DOM，目录按百章懒加载，显著降低长篇文本的首屏渲染压力。

### 2. 手机局域网「纯遥控手柄」模式
- **隐私保护与正文隔离**：手机端完全不传输、不展示任何小说文字，纯粹作为极简暗色触控手柄，保护私密性。
- **8 位临时验证 PIN 码**：服务端动态生成，**大小写不敏感**（手机输入小写字母自动校验通过）。
- **细粒度并发与设备上限门禁**：电脑端可自由设置允许连入的手机台数（默认 1 台，超过上限直接拒绝握手），可实时查看连入设备 IP/名称，并随时一键踢出或刷新 PIN；网络 I/O 完全独立于状态锁外，杜绝慢网络卡死并发。
- **虚拟滑板 (Virtual Trackpad)**：手机端中央设计有高灵敏度触控板，手指在上面**上下滑动**，电脑端即以 60fps 平滑平移滚屏；轻点直接向下翻页；自带 X/Y 轴防误触过滤与 `touchcancel` 异常状态自愈。
- **逐幕平滑导航**：手机端按“上一幕 / 下一幕”时，小说有分幕则在章节内逐幕平滑定位，到达章节首尾边界时顺畅跨章。
- **触觉与视觉反馈**：按键均支持微震动反馈（Haptic feedback）；自动启用防休眠（Wake Lock API），看书期间手机屏幕不熄屏。

### 3. 多重网络与系统安全屏障
- **阅读端本机隔离**：`/`、`/api/books`、`/api/book/content` 与 `/ws/reader` 仅允许本机访问；局域网设备只能打开 `/remote` 遥控页，无法直接读取书单或小说正文。
- **敏感凭据脱敏**：`/api/status` 对局域网非本机请求自动脱敏，不泄漏动态 PIN 码。
- **指令白名单清洗**：遥控端指令经过严密白名单过滤（仅允许翻页、滚屏、缩放、主题、全屏、幕切换等受控动作），阻绝任意非法参数执行。
- **路径穿越免疫**：白名单严格基于 `relative_to` 路径树判定，杜绝同名前缀越权与任意文件读取。
- **ReDoS 防御与检索熔断**：单行超长文本安全切片，全文搜索内置 120ms 防阻塞熔断机制。

### 4. 5 套精选护眼主题与专业中文排版
- **经典暖黄羊皮纸**：温润柔和，纸质书般舒适。
- **豆沙淡绿**：舒缓视觉疲劳，长时间阅读首选。
- **极简水墨白**：纯净高雅，高对比度。
- **夜间雅灰**：暗色模式，柔和不刺眼。
- **深邃纯黑 OLED**：纯黑极暗，手机遥控端与电脑端均完美适配，省电沉浸。
- **自由个性化设置**：字号（14px~36px）、行间距（1.4~2.6）、容器宽度（650px~1300px）、标准中文 2 字符缩进与优雅字体自由切换。

### 5. 毫秒级全文检索与断点续读
- 全书检索带主线程时间预算保护，显示所在章节与上下文摘要，高亮关键词，点击一键跳转。
- 像素级自动保存阅读进度，关闭浏览器后重新打开自动无缝续读。
- 书架条目支持移除与恢复，只改变本机书架显示，不会删除、移动或修改原文件。

## 🚀 快速上手

### 1. 依赖安装
推荐使用 Python 3.10+：
```bash
pip install -r requirements.txt
```

### 2. 启动服务
- **Windows 用户**：直接双击运行工程根目录下的 [`run.bat`](run.bat)。脚本会检测 Python 和依赖，缺少依赖时自动安装，并在异常退出时保留错误信息。
- **跨平台运行（Linux / macOS / Windows）**：
```bash
python server.py
```
启动后，系统会自动在局域网开启服务（默认端口 `8765`），并在电脑端默认浏览器中弹出阅读页面：`http://localhost:8765`。

### 3. 添加小说书库
- **方式一（内置目录递归）**：直接将 `.txt` 或 `.md` 小说文件（支持任意层级子目录）丢入项目的 `books/` 目录下，刷新页面即可读取。
- **方式二（自定义路径/目录挂载）**：
  复制 `config.example.json` 为 `config.json`，在 `custom_books` 列表中填入小说文件或整个文件夹的绝对路径（`config.json` 已被 `.gitignore` 保护，不会被提交，保护隐私）：
  ```json
  {
    "custom_books": [
      "D:\\novels\\斗破苍穹.txt",
      "D:\\novels\\my_library_folder"
    ]
  }
  ```
- **方式三（拖拽即读）**：在电脑浏览器中直接将任意 `.txt` / `.md` 文件拖入页面即可秒速解析阅读。

## 📱 手机无线遥控连接指南

1. **连入同一网络**：确保手机和电脑连接在同一个 Wi-Fi 下（或者手机直接连接电脑开启的“移动热点”）。
2. **打开遥控面板**：在电脑端顶栏点击 **“手机遥控”** 按钮。
3. **扫码或访问地址**：
   - 手机摄像头直接扫描弹窗中的二维码（URL 自动附带 PIN，省去手动输入的繁琐）；
   - 或在手机浏览器手动输入局域网地址（如 `http://192.168.137.1:8765/remote`）。
4. **身份校验与连接**：输入电脑端显示的 **8 位临时 PIN 码**（大小写均可），点击“立即连接电脑”。
5. **设备管理与调控**：
   - 电脑端弹窗可实时查看连入的手机型号与内网 IP；
   - 可随时点击“踢出”断开特定设备；
   - 可点击“刷新 PIN”重置密钥；
   - 可按需调整受控设备上限（1~10 台）。

## ❓ 常见问题排查 (FAQ)

<details>
<summary><strong>Q1: 手机扫码后打不开页面或提示“网络连接错误”？</strong></summary>

1. **确认同一网络**：请确认手机和电脑连接在同一个 Wi-Fi 下。
2. **移动热点直连（强烈推荐）**：若在公司/校园网存在“局域网 AP 隔离”，可在 Windows 电脑上开启“移动热点”，手机连接电脑热点即可 100% 畅通直连。
3. **防火墙放行**：Windows 首次运行会弹出防火墙提示，请勾选“允许在专用网络和公用网络上通信”。
</details>

<details>
<summary><strong>Q2: 为什么手机遥控端看不到小说文字？</strong></summary>

这是**核心设计原则**！手机端被特意设计为独立的“无线实体手柄”：
- 电脑端用于大屏高品质排版阅读；
- 手机端只负责手势滑板、翻页与功能控制；
- 手机端绝不接收、缓存或展示任何正文内容，彻底保护私密性，且极度省电、不消耗手机流量。
</details>

<details>
<summary><strong>Q3: 拖入某些老小说文件会不会乱码？</strong></summary>

不会。阅读器内置了全量缓冲的 `TextDecoder` 字符探测链，支持 UTF-8、GB18030、GBK、UTF-16LE、UTF-16BE 等全套中文字符集，完全消除了由于固定字节切片断裂造成的误退回乱码。
</details>
